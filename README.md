# digital-lab-prototype

This repository contains the Advanced Prototype of the 3D Digital Lab for Grade 9 STEM.

Live page (enable GitHub Pages):
https://lama855.github.io/digital-lab-prototype/

Files:
- index.html — client entry
- styles.css — UI styles
- main.js — Three.js 3D scene and interaction

How to preview locally:
1. Clone the repo or download files
2. From the project folder run:
   python3 -m http.server 8000
3. Open http://localhost:8000

Enable GitHub Pages (to get the public link):
1. Open the repository Settings → Pages
2. Under Source choose Branch: main and folder: /
3. Save; the site will appear within a few minutes at the URL above.

AI server (optional): server.js (not included here) — see earlier messages for server proxy example.
